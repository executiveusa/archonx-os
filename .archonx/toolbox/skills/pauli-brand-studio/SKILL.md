# Pauli Brand Studio

## Activation law

For every brand-kit, brand-voice, identity, image, website, application-interface, interactive-artifact, campaign, collateral, packaging, merchandise, or design-handoff task:

1. Read `AGENTS.md`.
2. Read `.archonx/toolbox/skills/mandatory-design-law/SKILL.md`.
3. Read every reference file in this directory in numeric order.
4. Inspect all available project sources and mandatory live repositories.
5. Create the capability matrix, source ledger, repository snapshot, conflict record, and prebuild score.
6. Do not generate creative work until the prebuild gate passes.
7. Run Brand, Design, Voice, and Rights Guardian review before release.
8. Block output below 8.5/10; target 9.0/10.

All reference files are binding. A later file extends earlier files but does not silently cancel them. Resolve conflicts using the source-priority order in `references/00-core-and-sources.md`.

## Hard release blockers

- Mandatory sources were not opened and recorded.
- Project repository, `AGENTS.md`, current architecture, or existing brand system was ignored.
- Prebuild score is below 8.5 or a critical axis is below 8.0.
- KAKU sequence is missing from a full brand book.
- Steve Krug usability fails.
- Generic AI slop, invented proof, fake claims, placeholder identities, or copied protected branding remains.
- Emojis are used as icons or design-system elements.
- Supplied logos, products, people, or approved assets were altered outside the explicit request.
- Rights, licensing, consent, provenance, or attribution is unresolved.
- Screenshot evidence, responsive verification, accessibility evidence, or rollback proof is missing where required.
- The creator is the sole reviewer.

## First response contract

Before designing, acknowledge the ZTE persona and return:

1. capability matrix;
2. source and repository inspection status;
3. project classification;
4. confirmed facts and inferences;
5. conflicts and missing sources;
6. prebuild readiness score;
7. recommended path;
8. one precise next question only when evidence cannot resolve it.

## Short rule

Research first. Establish brand truth. Make every decision source-traceable. Build the KAKU system. Pass Krug. Remove slop. Verify rights. Prove the result. Do not ship below the floor.
